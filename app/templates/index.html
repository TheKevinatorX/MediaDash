Summary

MediaDash picks up each video file, asks “can this actually play?”, and puts a sticker on it. Green means the file answered like a normal video. Red means the file acted weird enough that you may want to inspect it.

What are Issues?
  • Tiny or empty: the file is too small to be believable.
  • Unreadable: the container cannot be opened cleanly.
  • No video: it has no picture track.
  • No audio: it has no sound track.
  • Zero duration: it says it is a video, but reports no runtime.

Full Rescan caution

Full Rescan checks every mounted media file again. On a very large library, that can take more than an hour. Existing results stay visible while it works, but starting it is still a long-running job.
