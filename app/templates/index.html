Plex Connection
Your Plex server URL and authentication token

The local network address of your Plex server. Usually starts with http://192.168. followed by your server's IP and port :32400.

Your Plex authentication token. To find it: open Plex Web → click any media item → click the ⋮ menu → "Get Info" → "View XML" — the token appears in the URL as X-Plex-Token=....
Leave blank to keep the existing token unchanged.

Naming Rules
How MediaDash determines expected filenames and directories. Changes apply immediately — refresh your library to re-check names.

Determines the episode numbering style in expected filenames and directories on the Naming page.

Whether season directory names are zero-padded. Most Plex setups use Season N (no padding).

How close the year in a filename must be to the year stored in Plex metadata.

Replace [: < > " / \ | ? *] with

Characters that are illegal in Windows/NTFS filenames are replaced with this string when building expected names. Default is - (space-dash-space). Use an empty string to simply remove them.
