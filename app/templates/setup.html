Welcome to
MediaDash
A self-hosted Plex dashboard for your home media server. Takes about 2 minutes to set up.
Library overview with total size and watch-time stats
Filename convention checker for movies and TV shows
Oversized file detection and bloat analysis
Full-library search and column filtering
You'll need your Plex server URL (usually http://192.168.x.x:32400) and your Plex authentication token.
Step 01 of 03
Connect to Plex
Enter your Plex server details. Both fields are required.
Server URL Required
Your Plex server's local address. Usually starts with http://192.168. followed by your server's IP and port :32400.
Plex Token Required
Find it in Plex Web: click any media item → ⋯ menu → Get Info → View XML. Look for X-Plex-Token= in the URL.
A successful connection test is required before you can continue.
Step 02 of 03
Choose Libraries
Select which Plex libraries MediaDash should track. Only Movie and TV Show libraries are supported.
